# 🐾 PetFlow 

PetFlow merupakan aplikasi Point of Sale (POS) sederhana yang dikembangkan untuk membantu pengelolaan pet shop. Sistem ini mendukung pengelolaan produk, transaksi penjualan, keranjang belanja, serta manajemen pengguna berdasarkan role Admin dan Cashier.

## ✨ Features

### Admin

* Login sebagai Admin
* Menambah produk
* Menghapus produk
* Melihat daftar produk
* Mengelola data kasir
* Melihat omset penjualan

### Cashier

* Login sebagai Cashier
* Melihat daftar produk
* Menambahkan produk ke keranjang
* Melihat isi keranjang
* Melakukan checkout transaksi

---

## 🖥️ Tech Stack

* Java
* MySQL
* JDBC (Java Database Connectivity)
* NetBeans / VS Code
